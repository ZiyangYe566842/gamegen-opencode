# Changelog

## 0.10.3 — 2026-10-12

- Convert the v10.2 installer bundle into an independent repository.
- Add English/Chinese documentation, MIT license, contributor templates, CI, and release checks.
- Add a starter demo that does not call AI providers; include dependency lockfiles.
- Fail feedback acceptance when unresolved issues remain or evidence belongs to an earlier request; fail asset validation on missing files.
- Propagate QA/final-acceptance failures to CLI exit status.
- Reject invalid job selectors and export using direct process arguments.
- Omit environment backups and uploaded references from source exports.
- Preserve existing environment configuration and existing CLI names in the local installer.

Original OpenCode agent roles, project workflow skills, model-profile layout, media input, and iteration framework are retained.
